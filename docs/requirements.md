# 📌 เอกสารข้อกำหนดระบบ (System Requirement Specification)
## ระบบสั่งอาหารออนไลน์และบริหารร้านลูกชิ้น (งบประมาณ 0 บาท)

---

### 1. ภาพรวมระบบ (System Overview)
ระบบเว็บแอพพลิเคชันสำหรับการสั่งอาหารออนไลน์ สะสมแต้ม บริหารจัดการสต็อก และวิเคราะห์ต้นทุน/กำไรสำหรับร้านลูกชิ้น โดยออกแบบให้เป็น **Single Page Application (SPA)** รองรับการทำงานแบบ **Progressive Web App (PWA)** เน้นการใช้งานบนมือถือ (Mobile-First) 

* **Frontend Hosting:** GitHub Pages (งบ 0 บาท)
* **Backend Database:** Firebase Realtime Database / Spark Plan (งบ 0 บาท)
* **Target Users:** ลูกค้าสั่งซื้อหน้าร้าน/จัดส่ง, พนักงาน/เจ้าของร้าน

---

### 2. สรุปฟังก์ชันการทำงานหลัก (Feature List)

#### 📱 2.1 ฝั่งลูกค้า (Customer UI - `index.html`)
1. **การเข้าถึง & หมวดหมู่:**
   * เปิดใช้งานผ่าน QR Code หรือ URL โดยไม่ต้องดาวน์โหลดแอป
   * แสดงสินค้าแยกตามหมวดหมู่ (Horizontal Scroll Filter) และแสดงสินค้าขายดี (Best Seller)
2. **การสั่งซื้อ (Ordering):**
   * **ระบบสั่งแบบ Guest:** ไม่อยากใส่เบอร์โทร ก็กดสั่งได้ (ได้ Order ID สำหรับติดตามสถานะ)
   * **ระบบสมาชิกเบอร์โทรศัพท์:** ใส่แค่เบอร์โทรเพื่อสะสมแต้ม ดูประวัติสั่งซื้อย้อนหลัง และกดปุ่ม **"สั่งซ้ำเมนูเดิม (Re-order)"** ในคลิกเดียว
   * **การรับสินค้า:** เลือกได้ระหว่าง "จัดส่งตามที่อยู่" (ส่งพิกัด GPS) หรือ "มารับเองหน้าร้าน" (มีปุ่ม Google Maps นำทาง)
3. **ตัวเลือกเสริมก่อนยืนยัน (Add-ons Modal):**
   * เลือกระหว่าง เสียบไม้ / ใส่ถุง (ไม่เสียบ) / รับไม้เสียบแยก
   * เลือกรับ/ไม่รับ: พริกทอด, แตงกวา, ถ้วยน้ำจิ้ม
   * ช่อง Comment พิมพ์หมายเหตุเพิ่มเติมถึงร้าน (เช่น "ขอทอดกรอบๆ", "แยกน้ำจิ้ม")
4. **การชำระเงิน (PromptPay QR):**
   * คำนวณยอดเงินสุทธิอัตโนมัติ (หักส่วนลดโปรโมชั่น)
   * สร้าง PromptPay QR Code แบบใส่ยอดเงินให้อัตโนมัติ พร้อมช่องแนบ Slip การโอนเงิน
5. **การติดตามสถานะ Real-time (In-App Notification):**
   * อัปเดตสถานะออเดอร์สดบนหน้าจอ (`รอดำเนินการ` -> `กำลังทำ` -> `เสร็จแล้ว`) พร้อมเสียงเตือนเมื่ออาหารเสร็จ

---

#### 🏪 2.2 ฝั่งร้านค้า (Merchant Dashboard - `admin.html`)
1. **จัดการออเดอร์ (Order Management):**
   * เสียงเตือนเมื่อมีออเดอร์ใหม่ พร้อมแสดงรายละเอียด Comment และ Add-ons ชัดเจน
   * ปุ่มกดเปลี่ยนสถานะออเดอร์ เพื่อส่งสัญญาณกลับไปยังหน้าจอลูกค้า
   * ปุ่มพิมพ์ใบสรุปออเดอร์ (Print Slip) ออกเครื่องพิมพ์ความร้อน (Thermal Printer)
2. **ระบบ POS เพิ่มแต้มหน้าร้าน:**
   * ลงทะเบียนหรือพิมพ์เบอร์โทรลูกค้าหน้าร้านเพื่อกดเพิ่มแต้ม (+1) อัตโนมัติ
3. **จัดการสินค้า & สต็อกอัจฉริยะ (Smart Inventory):**
   * กำหนดสถานะสินค้า: `🟢 ขายปกติ` / `🟡 สินค้าหมด` / `🔴 ซ่อนเมนู`
   * ระบบตัดสต็อกอัตโนมัติเมื่อมีการสั่งซื้อ
   * ปุ่ม **"One-Click Stock Reset"** คืนค่าสต็อกตั้งต้นประจำวัน
4. **ตั้งค่าร้านค้า & โปรโมชั่น:**
   * แก้ไขชื่อร้าน โลโก้ และตั้งค่าส่วนลด (เช่น ซื้อครบ 50 บาท ลด 5 บาท, 120 บาท ส่งฟรี, ซื้อครบ 10 ครั้ง แถมฟรี)

---

#### 📊 2.3 ระบบวิเคราะห์ต้นทุน กำไร และจุดคุ้มทุน (Smart Cost & Break-even Analytics)
1. **Direct Cost Tracking:** บันทึกต้นทุนวัตถุดิบตรงต่อหน่วย (ลูกชิ้น + น้ำจิ้ม + ไม้)
2. **Hidden & Operating Cost Tracking:** บันทึกต้นทุนแฝง (แก๊สหุงต้ม, ถุงพลาสติก, พริกสด, ค่าน้ำ/ไฟ) พร้อมคำนวณรอบการใช้/การเติมแก๊สให้อัตโนมัติ
3. **Break-even Analysis:** คำนวณจุดคุ้มทุนรายเมนูว่าต้องขายกี่ไม้/กี่ชุด ถึงจะครอบคลุมต้นทุนแฝงประจำเดือน พร้อมระบบ Smart Advice แนะนำการทำโปรโมชั่น

### 4. Prompt สำหรับคัดลอกไปใช้ใน Google AI Studio

คุณสามารถ copy ข้อความในกล่องด้านล่างนี้ไปวางใน **Google AI Studio** เพื่อให้ AI เจเนอเรตโค้ดทั้งโปรเจกต์ได้เลย:

```text
คุณคือ Senior Full-Stack Developer ที่เชี่ยวชาญการสร้าง Web Application ด้วย HTML5, Tailwind CSS, JavaScript (ES6+), และ Firebase Realtime Database

โปรดสร้างโค้ดสำหรับระบบสั่งอาหารร้านลูกชิ้น (Single File / Budget 0 Baht) ที่รองรับการทำงานบนมือถือ (Mobile-First Responsive PWA) โดยแบ่งโค้ดออกเป็น 2 ไฟล์หลัก:

1. ไฟล์ `index.html` (สำหรับลูกค้า):
   - รองรับการกรอกเบอร์โทรสะสมแต้ม หรือเลือกสั่งแบบ Guest (ไม่ใส่เบอร์)
   - แถบกรองหมวดหมู่อาหารแบบ Horizontal Scroll
   - Modal เลือกตัวเลือกเสริมก่อนชำระเงิน (เสียบไม้/ไม่เสียบ, รับพริก/แตงกวา/ถ้วยน้ำจิ้ม, ช่อง Comment เพิ่มเติม)
   - เลือกรูปแบบการรับสินค้า: "จัดส่งตามที่อยู่ (มีปุ่มกดส่งพิกัด GPS)" หรือ "มารับเองหน้าร้าน"
   - คำนวณโปรโมชั่นอัตโนมัติ (ซื้อครบ 50 บาท ลด 5 บาท, ซื้อครบ 120 บาท ส่งฟรี)
   - ระบบสร้าง PromptPay QR Code อัตโนมัติตามยอดเงินสุทธิ พร้อมช่องแนบ Slip
   - หน้าติดตามสถานะออเดอร์แบบ Real-time ดึงข้อมูลจาก Firebase Realtime Database พร้อมส่งเสียงเตือนเมื่อสถานะเปลี่ยนเป็น "ready"

2. ไฟล์ `admin.html` (สำหรับเจ้าของร้าน/พนักงาน):
   - ใส่ PIN Code 4 หลักเพื่อเข้าใช้งาน
   - แสดงรายการออเดอร์เข้าใหม่แบบ Real-time พร้อมเสียงเตือน แสดง Comment และ Add-on เด่นชัด
   - ปุ่มเปลี่ยนสถานะออเดอร์ (pending -> cooking -> ready)
   - ระบบ POS เพิ่มแต้มหน้าร้านโดยใช้เบอร์โทรศัพท์ลูกค้า
   - ระบบจัดการสต็อก: ปรับสถานะ (ขายปกติ/สินค้าหมด/ซ่อนเมนู), ตัดสต็อกอัตโนมัติ, และปุ่ม One-Click Reset สต็อกประจำวัน
   - ระบบ Dashboard วิเคราะห์ต้นทุนแฝง (Hidden Cost Log) เช่น ค่าแก๊ส, ค่าถุง และคำนวณจุดคุ้มทุน (Break-even Point) แยกตามรายการอาหาร

โปรดใช้ Tailwind CSS ผ่าน CDN และเชื่อมต่อ Firebase SDK (v9+ compat mode) เพื่อความง่ายในการใช้งานบน GitHub Pages 
```

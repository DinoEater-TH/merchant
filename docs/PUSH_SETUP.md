# เปิดใช้แจ้งเตือนออเดอร์ใหม่แม้ปิดแอป (Push Notification)

ระบบแจ้งเตือนทำงาน 3 ระดับ:

| สถานการณ์ | วิธีแจ้งเตือน |
| --- | --- |
| แอปเปิดอยู่ (แอดมิน) | เสียง + แถบแจ้งเตือนในแอป |
| แอปอยู่เบื้องหลัง / เว็บสลับแท็บ | เสียง + Notification ของอุปกรณ์ |
| **ปิดแอป / ปิดแท็บเบราว์เซอร์แล้ว** | **Push Notification (FCM)** — ต้องทำขั้นตอนด้านล่างให้ครบ |

## ฝั่งอุปกรณ์ (ทำแล้วในโค้ด ไม่ต้องทำอะไรเพิ่ม)

- แอป Android: เมื่อเข้าโหมดแอดมิน (ใส่ PIN) แอปจะสมัครรับ Push อัตโนมัติ และขอสิทธิ์แจ้งเตือน
- เว็บแอดมิน: ไปที่ **ตั้งค่า → 🔔 เปิดการแจ้งเตือนบนเบราว์เซอร์** และกดอนุญาต

## ขั้นตอนเปิดใช้ Push จริง (ทำครั้งเดียว)

### 1) เปิดใช้งาน Firebase Cloud Functions
Cloud Functions ต้องใช้แผน Blaze (แบบจ่ายตามใช้จริง มีโควต้าฟรี) จึงจะส่ง Push ได้
- เข้า https://console.firebase.google.com/project/dinoeater-merchant
- ไปที่ **Upgrade** → เลือกแผน **Blaze** → ผูกบัตรเครดิต (Firebase จะไม่เรียกเก็บถ้าไม่เกินโควต้าฟรี)

### 2) Deploy ฟังก์ชันส่งแจ้งเตือน
```bash
cd functions
npm install
cd ..
npx firebase-tools deploy --only functions --project dinoeater-merchant
```
ฟังก์ชัน `onNewOrderPush` ใน `functions/index.js` จะฟังการเปลี่ยนแปลงของข้อมูลร้าน และส่ง Push ไปยังอุปกรณ์แอดมินทุกเครื่องที่ลงทะเบียนไว้ (เก็บ token ที่ `shops/dinoeater-merchant/fcmTokens`)

### 3) เปิดใช้ Push สำหรับเว็บแอดมิน (ถ้าต้องการแจ้งเตือนบนคอมแม้ปิดแท็บ)
1. Firebase Console → **Project settings → Cloud Messaging → Web Push certificates → Generate key pair**
2. คัดลอกคีย์ที่สร้างได้ ไปวางใน `docs/prototype/admin.html` ที่ตัวแปร `FCM_VAPID_KEY`
3. Deploy Hosting อีกครั้ง: `npx firebase-tools deploy --only hosting --project dinoeater-merchant`

### 4) ทดสอบ
1. เปิดแอป/เว็บแอดมิน และเข้าโหมดแอดมิน (อุปกรณ์จะลงทะเบียน token เอง)
2. ปิดแอปให้สนิท (หรือปิดแท็บเบราว์เซอร์)
3. สั่งอาหารจากหน้าร้านลูกค้า (เว็บหรือแอป)
4. อุปกรณ์แอดมินควรได้รับแจ้งเตือนพร้อมเสียงและสั่น แม้แอปจะปิดอยู่

> หมายเหตุ: ถ้าปิดเครื่อง/โหมดเครื่องบิน หรือถอนการติดตั้งแอป จะไม่ได้รับแจ้งเตือน และ Android ที่ "Force stop" จะไม่ได้รับ Push จนกว่าจะเปิดแอปอีกครั้ง — เป็นข้อจำกัดของระบบปฏิบัติการทุกแอป
